Die Monitoring Collection beinhaltet eine Reihe von Applikationen zur Überwachung von Hardwarekomponenten wie bspw. dem Prozessor, Laufwerken, Netzwerk- und Grafikkarten, Audiogeräten, dem Hauptspeicher sowie existierenden Batterien. Ein Download der aktuell verfügbaren Version 1.11.0 ist zusätzlich über ausgewählte Softwarearchive möglich, die Installation selbst ist sehr einfach aber effizient gehalten. Die Verwendung der Applikationen ist für Privatanwender kostenlos. Sollten diese im geschäftlichen Umfeld genutzt werden, bitte ich um vorherige Kontaktaufnahme und Registrierung.

Im Gegensatz zu ebenfalls in diesem Umfeld existierenden Applikationen zeichnen sich alle Applikationen durch folgende Merkmale aus:
  • ein Aufruf erfolgt bequem aus der Windows-Taskleiste, die jeweilige Darstellung zeigt den aktuellen Status mittels konfigurierbarer Grafiken und Farben an,
  • es werden Technologien zur Bereitstellung der ermittelten Werte mittels Schnittstellen zur Nutzung in Drittapplikationen unterstützt,
  • sämtliche Optionen wie beispielsweise die grafische Darstellung, der Zeitpunkt der Statusermittlung sowie von Benachrichtigungen sind in hohem Maße konfigurierbar,
  • die Installationsgröße ist gering und die Applikationen nutzen nur minimale Hardwareresourcen,
  • es stehen verschiedene Sprachen (aktuell deutsch sowie englisch) zur Verfügung, eine Erstellung von Sprachdateien ist mit geringem Aufwand möglich.
Überwachung der Wiedergabe- und Aufnahmegeräte sowie Funktionen zur Änderung der Wiedergabeoptionen
Überwachung des Batterieladestandes, dem technischen Zustand und Funktionen zur Änderung der Energieoptionen
Überwachung von physikalischen Laufwerken und Netzwerklaufwerken, Verzeichnissen sowie Freigaben, Management von USB-Laufwerken, Anzeige technischer Informationen, S.M.A.R.T.-Werten sowie Funktionen zur Analyse der Belegung, der Fragmentierung und doppelter Dateien
Überwachung von Grafikkarten, Anzeige von technischen Informationen bzw. Sensorinformationen (nur ATI/NVIDIA), Funktionen zur Änderung der Bildschirmdarstellung
Überwachung des Hauptspeichers, Anzeige von technischen Informationen und der Hardwarebelegung, Funktionen zur Freigabe von Hauptspeicher
Überwachung von Netzwerkkarten, Anzeige von technischen Informationen, Funktionen zur Verbindungsanalyse, dem Aufspüren von Wifinetzwerken sowie dem Senden von Netzwerkkommandos
Überwachung des Prozessors, Anzeige von technischen Informationen, Funktionen zur Analyse von Prozessen, Services und Treibern

Der Status der Überwachung kann mittels der Konfigurationseinstellungen den eigenen Wünschen angepasst werden.

Zusätzlich zu den vorgestellten Applikationen befinden sich im Installationspaket zugehörige Gadgets, womit sich ein bestimmter Status direkt auf dem Desktop darstellen lässt.

This tool collection contains applications to monitor hardware related components of your computer, like disks, network and graphics cards, the system processor, audio devices, memory or the built-in battery. The download of the latest published version 1.11.0 can be started additionally by using selected Software Archives. All tools are free for personal use; commercial licenses are available after the registration by completing the request form, any feedback can be submitted by using the feedback form.

Unlike to other existing applications in this context, all applications are characterized by the following features:
  • each functionality can be opened directly from the Windows notification area, the respective icon indicates the current status,
  • interfaces and shared technologies are implemented to use determined values in 3rd party applications,
  • all applications like the graphical display, the refresh rate and the display of notifications are highly configurable,
  • the installation size is very low, each component will use minimal hardware resources,
  • different languages (currently German and English) are supported, language packs can be made easily with small effort.
Monitoring of record and playback devices, functionalities to change the sound scheme
Monitoring of the battery charge rate, the technical health and functionalities to change the power plan
Monitoring of physical and network devices, shares and directories, management of USB devices, display of technical information including S.M.A.R.T. values and functionalities to analyze disks and folders, to determine the fragmentation and to find duplicate files
Monitoring of graphic cards, display of technical and sensor information (ATI/NVIDIA only), functionalities to manipulate the screen display and resolution
Monitoring of main memory, display of technical and hardware information, functionalities to release unused memory
Monitoring of network devices, display of technical information, functionalities to analyze network connections, to find Wifi networks and to send network commands
Monitoring of processors, display of technical and hardware information, functionalities to analyze processes, services and drivers

The monitoring status can be configured in different ways for your personal needs.

In addition to the presented applications, appropriate gadgets are included to display the status directly on your desktop.
