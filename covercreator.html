Der MediaTip Cover Creator kann zur Erstellung von Compact, Disc Versatile und Bluray Disk Covern verwendet werden. Dabei sind verschiedene Stile, Effekte und Labels auswählbar. Ebenfalls besteht die Möglichkeit, Wasserzeichen zu verwenden. Die erstellten Cover können nach Erstellung in allen gängige Grafikformaten und unter Verwendung optionaler Platzhalter gespeichert werden. Die Verwendung der Applikation ist für Privatanwender kostenlos.

Ein Download der aktuellen verfügbaren Version 1.1.1 (Installer, Portable) ist über den jeweiligen Link möglich.

The MediaTip Cover Creator can be used to create Compact, Disc Versatile and Bluray disc cover. For creating diverse styles, effects and labels can be selected, additionally you can use watermarks. The created covers can be saved in all common graphic formats, placeholders are available to easily generate unique file names. The tool is free for personal use.

The download of the latest published version 1.1.1 (Installer, Portable) can be started by clicking the appropriate link.
